# 🤖 ARCANA — Bale Bot

این بسته یک هسته ماژولار و سبک برای بات بله است.

## امکانات فعلی
- `/start` و راهنمای کوتاه
- سیستم «اصل» با ثبت فقط برای مالک/مدیر
- جایگزینی اصل قبلی
- حافظه آموزشی کاربر
- جرئت یا حقیقت
- آمار پیام و رتبه
- روزانه/XP پایه
- تشخیص درخواست GIF به‌صورت نقطه اتصال
- Health Check
- ذخیره‌سازی اتمیک JSON
- مدیریت خطای پایه تا خرابی یک آپدیت کل سرور را متوقف نکند

## نصب
1. Node.js 18 یا بالاتر.
2. `npm install`
3. `.env.example` را به `.env` تبدیل کن.
4. توکن خودت را فقط در متغیر محیطی `BALE_BOT_TOKEN` قرار بده.
5. `npm start`

## بررسی سریع
`npm run check`

سپس:
- `/health`
- `/`

## نکته
این نسخه عمداً API بله را حدس نمی‌زند و فقط از الگوی Bot API استفاده می‌کند. قبل از اتصال نهایی، endpoint و فرمت دقیق API/وبهوک بله را با مستندات فعلی سرویس خودت تطبیق بده.

ماژول‌های سنگین مثل رندر واقعی GIF و گزارش تصویری هفتگی باید به سرویس/کتابخانه واقعی محیط اجرای تو متصل شوند؛ این بسته برای جلوگیری از کد جعلی یا endpoint حدسی آن‌ها را شبیه‌سازی نمی‌کند.

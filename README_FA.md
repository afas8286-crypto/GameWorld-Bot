# ARCANA

بات گروهی ماژولار برای بله.

## راه‌اندازی
1. Node.js نسخه 18 یا بالاتر نصب باشد.
2. `npm install`
3. مقادیر `.env.example` را در محیط اجرا تنظیم کنید.
4. `npm start`
5. برای ثبت Webhook:
   `POST /setup-webhook`

## نکته مهم
توکن بات را داخل کد یا ZIP قرار ندهید. آن را به صورت Environment Variable تنظیم کنید.

`BALE_API_BASE` عمداً قابل تنظیم است تا از حدس‌زدن آدرس API جلوگیری شود.

## مسیرها
- `GET /`
- `GET /health`
- `POST /webhook`
- `POST /setup-webhook`

## قابلیت‌های موجود در این هسته
Start/Help، پروفایل و XP، Daily/Streak، جرئت‌وحقیقت، حافظه پایه، اصل پایه، تنظیمات، لاگ، ذخیره‌سازی امن‌تر، مدیریت خطای Webhook.

قابلیت‌های وابسته به API واقعی بله یا موتور رندر GIF باید بر اساس مستندات رسمی API به ماژول‌های مخصوص خود متصل شوند و در این بسته وانمود نشده که API تأیید نشده یا GIF واقعی آماده است.

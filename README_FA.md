# ARCANA
بات گروهی حرفه‌ای Bale.

نام نمایشی فقط **ARCANA** است و عبارت PRO MAX در رابط کاربری نمایش داده نمی‌شود.

## اجرا
1. Node.js
2. `npm install`
3. `.env.example` را به `.env` تبدیل کن.
4. توکن را فقط در متغیر محیطی/تنظیمات امن سرور قرار بده.
5. `BALE_API_BASE` را مطابق مستندات رسمی و فعلی Bale تنظیم کن.
6. `PUBLIC_URL` باید HTTPS باشد.
7. `npm start`

هسته شامل webhook، شروع/راهنما، XP/Level، پروفایل، حافظه غیرحساس، جرئت/حقیقت، تنظیمات، health check و مدیریت خطا است. قابلیت‌های وابسته به API مدیریتی یا موتور رندر رسانه فقط پس از اتصال واقعی فعال می‌شوند.
